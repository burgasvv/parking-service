
# ___Parking-Service API___

## Версии
+ Ktor 3.4.0
+ OpenJDK 24
+ Gradle 9.2.1

## Основной стек зависимостей
+ Exposed DB
+ Postgresql
+ Security
+ Routing
+ Serialization
+ Kafka
+ Redis
+ Swagger

## Описание
    API для организации работы парковок и автомобилей пользователей

## Запуск приложения
* > Запустить приложение с помощью compose.yaml
* > Протестировать запросы в swagger по ссылке http://localhost:9000/swagger
